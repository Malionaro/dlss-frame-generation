## Vulkan Frame Generation 0.1.0-alpha

First public alpha for **Minecraft 26.3** (Fabric, Vulkan backend). Experimental: back up your worlds before testing.

### Highlights

- **DLSS Multi Frame Generation up to 6×** on RTX 50 (2× on RTX 40). HUD-less colour, depth, dense motion vectors and a separate UI layer; the provider accepted every frame on an RTX 5080.
- **DLSS Super Resolution and DLAA** with the DLSS 4.5 transformer presets (K/M/L) and a truly reduced world resolution.
- **NVIDIA Reflex** low latency with optional frame cap.
- **Shader packs on Vulkan:** cooperates with Iris 1.12 (Vulkan build) and Vitrail. Frame generation runs on top of the pack; auto mode switches it on when a pack starts.
- **Hybrid hardware ray tracing** streamed per chunk section, with textured reflections, alpha-tested shadows through leaves and flowers, and point lights.
- **AMD FSR 3.1** Vulkan route and a named FSR 3.1 fallback on Intel.
- New **settings screen with sliders**, a **Sodium video-settings page**, and **F3 lines** for frame times and the upscaling resolution.

### Fixes in this build

- Picture no longer wobbles with DLSS and dynamic resolution (aspect-exact render sizes, history kept, jitter only while DLSS accepts frames).
- Sharper distant terrain: texture mip bias and a jitter sequence matched to the upscale factor.
- Menu backgrounds no longer swim: frame generation and jitter are off while a menu covers the world.
- No camera freeze after alt-tabbing back into the game.
- Ultra Performance no longer freezes the image.
- No crash when joining a world with an Iris shader pack.
- Ray tracing no longer freezes the game while walking or breaking blocks.
- The Reflex frame limiter no longer caps FPS when pacing is off.

### Known limitations

- With Iris shader packs there is no DLSS upscaling (Iris has no render-scale hook); the extra FPS come from frame generation, and the mod's own RT stays off.
- Ray tracing, DLSS Ray Reconstruction, AMD and Intel paths still need hardware testing.
- AMD FSR 4 and Intel XeSS frame generation are not available (official runtimes not bundled).
- Windows only. Requires Minecraft's Vulkan backend.

### Install

Drop `dlss-frame-generation-0.1.0-alpha.jar` into `mods` next to Fabric API (Fabric Loader 0.19.5+). All native files are inside the JAR. Set the graphics backend to Vulkan, then open **Options → Video Settings → Frame Generation** or press **End**.
