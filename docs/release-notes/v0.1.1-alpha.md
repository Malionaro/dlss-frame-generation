## Vulkan Frame Generation 0.1.1-alpha

Second alpha for **Minecraft 26.3** (Fabric, Vulkan backend). Experimental: back up your worlds before testing.

### New

- **Exact motion vectors for entities:** moving mobs, players, boats and minecarts get their true movement, and limbs, heads and turning bodies are tracked per model part. Frame generation and DLSS smear much less around animated entities.
- **Reactive mask:** pixels the previous frame cannot explain (particles, fire, animated water, disocclusion) are marked for DLSS (bias-current-colour hint) and FSR 3.1 (reactive mask), so they stop ghosting.
- **Ray Reconstruction with RT:** turning ray tracing on also enables DLSS Ray Reconstruction when the GPU supports it, so traced shadows and reflections are denoised. It can be turned off again.
- **NVIDIA Streamline 2.14.16** with DLSS 310.9.16.

### Fixes

- Ray tracing follows the DLSS jitter and the real field of view (sprinting, speed effects, spyglass), so RT shadows no longer drift against the image.
- Ray tracing stays exact far from the world origin (section-local geometry, camera-centred scene origin).
- The ray-traced scene follows the camera, so third person and spectator views are covered.
- No camera freeze after alt-tabbing back into the game.

### Updated

- Fabric API 0.163.0+26.3, Fabric Loom 1.19.1, Gradle 9.8.1.

### Known limitations

- With Iris shader packs there is no DLSS upscaling (Iris has no render-scale hook); the extra FPS come from frame generation, and the mod's own RT stays off.
- Ray tracing, Ray Reconstruction, AMD and Intel paths still need more hardware testing.
- Windows only. Requires Minecraft's Vulkan backend.

### Install

Drop `dlss-frame-generation-0.1.1-alpha.jar` into `mods` next to Fabric API (Fabric Loader 0.19.5+), remove the old version first, set the graphics backend to Vulkan, then press **End** in game.
