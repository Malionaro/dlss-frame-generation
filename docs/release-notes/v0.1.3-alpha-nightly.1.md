## Vulkan Frame Generation nightly (after 0.1.2-alpha)

Untested nightly build for **Minecraft 26.3** (Fabric, Vulkan backend). Expect bugs; back up your worlds. The JAR still carries the version `0.1.2-alpha` in its name.

### Fixes

- **Ray tracing no longer freezes the picture.** With RT on, Ray Reconstruction rejected every frame once dynamic resolution dropped below its minimum render size (e.g. 1280x720 for Quality at 1440p), so the camera seemed stuck. Dynamic resolution now asks DLSS for the smallest allowed size per mode and never goes below it.
- **DLAA is no longer scaled below native**, which DLSS rejected the same way.

### Note

Extra FPS and the NVIDIA overlay (Alt+Z) frame counter only appear with **Frame Generation enabled**: press **End** in game and turn on Frame Generation (2x to 4x).

### Install

Replace the old JAR in `mods` (Fabric Loader 0.19.5+, Fabric API, Vulkan backend).
