## Vulkan Frame Generation nightly 4 (after 0.1.2-alpha)

Untested nightly build for **Minecraft 26.3** (Fabric, Vulkan backend). It contains a large amount of new, untested RT engine code: expect bugs and back up your worlds. The JAR still carries the version `0.1.2-alpha` in its name.

### New: own RT engine

When ray tracing is on, the mod renders the near world with its own ray-traced engine. With an Iris shader pack active it stays off (frame generation keeps working).

- **Real block geometry:** plants, flowers, torches, stairs, slabs, fences, panes and leaves are traced as their actual block models with exact textures and alpha.
- **Mobs and players in RT:** their model parts, with each part's texture colour, cast exact shadows and show in reflections and under water.
- **Particles in RT:** smoke, splashes and flames show in reflections; flames, lava and sparks glow. Particles in front of RT surfaces keep their normal look.
- **RT draws the near terrain:** Minecraft skips terrain the RT engine fully covers, which saves GPU time. Falls back to vanilla terrain automatically if RT stops; can be turned off under *Ray tracing → RT Engine Draws Near Terrain*.
- **Volumetric clouds** replace vanilla's flat clouds while RT runs.
- **Own denoiser:** RT lighting is accumulated over several frames when Ray Reconstruction is off.
- **Rain in front of RT surfaces** is drawn by the RT engine.
- **RT range up to 96 blocks**, with coarser geometry (LOD) beyond 48 blocks. Default stays 48.
- **RT shader packs:** own loader for RT shaders from the `rtshaderpacks` folder (with a template), selectable live under *Ray tracing → RT Shader Pack*. Iris packs keep loading through Iris.
- **RT timing in the log:** every 5 s `latest.log` shows the RT pass GPU and CPU time.

### Fixes

- RT was never visible on some setups: raster depth is now converted with the camera's real inverse projection.
- Turning RT on no longer switches Ray Reconstruction on, which froze the picture. Configs from earlier builds have RR turned off once.
- Much fewer rays per pixel (the previous build could drop to single-digit FPS).
- NaN guard for the RT image.

### Known issues

- None of the RT engine is tested on hardware yet.
- Ray Reconstruction may still freeze the picture; test RT without it first.
- Brightness and colours are not tuned yet.

### Install

Replace the old JAR in `mods` (Fabric Loader 0.19.5+, Fabric API, Vulkan backend).
