## Vulkan Frame Generation nightly 7 (after 0.1.2-alpha)

Untested nightly for **Minecraft 26.3** (Fabric, Vulkan backend). Back up your worlds. The JAR still carries the version `0.1.2-alpha` in its name.

### Fix

- **The RT pass now records into its own command buffer.** Recorded into Minecraft's current command buffer, the RT shader never started, so RT drew nothing. Like the RT renderers for Minecraft's Vulkan backend, the pass now uses a transient command buffer that Minecraft executes in order. Existing configs are switched over once.

The RT debug lines from nightly 6 stay in `latest.log` (`RT debug`, `RT shader`, `RT self-check`).

### Please send

Turn RT on, walk around for about 30 seconds and send `latest.log` plus a screenshot.

### Install

Replace the old JAR in `mods` (Fabric Loader 0.19.5+, Fabric API, Vulkan backend).
