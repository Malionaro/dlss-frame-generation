## Vulkan Frame Generation 0.1.2-alpha

Hotfix for **0.1.1-alpha**. Please update if you installed 0.1.1-alpha.

### Fix

- **DLSS, DLSS Frame Generation and Ray Reconstruction work again on NVIDIA.** 0.1.1-alpha updated NVIDIA Streamline to 2.14.16 but kept the old file hashes, so the mod rejected its own NVIDIA runtime files at startup and showed "not available on this system". The build now checks every bundled NVIDIA file against the trusted hash list, so this cannot ship again.

Everything else is unchanged from 0.1.1-alpha: exact entity motion vectors (including limbs and heads), the reactive mask for particles and water, Ray Reconstruction with RT, the RT precision and jitter fixes, Streamline 2.14.16 with DLSS 310.9.16. See [v0.1.1-alpha](v0.1.1-alpha.md) for the full list.

### Install

Replace the old JAR with `dlss-frame-generation-0.1.2-alpha.jar` in `mods` (Fabric Loader 0.19.5+, Fabric API, Vulkan backend).
