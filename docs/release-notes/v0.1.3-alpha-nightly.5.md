## Vulkan Frame Generation nightly 5 (after 0.1.2-alpha)

Untested nightly build for **Minecraft 26.3** (Fabric, Vulkan backend). Diagnostic build for the RT engine; back up your worlds. The JAR still carries the version `0.1.2-alpha` in its name.

### Fixes

- **Near chunks no longer vanish.** *RT Engine Draws Near Terrain* is off by default again (and turned off once for existing configs): on setups where the RT pass draws nothing, the skipped terrain left holes.
- The RT pass runs once per frame. The capture hook can fire more than once per frame, and the pass ran on each call.

### Diagnostics

Every 5 s `latest.log` now has a line like:

```
RT pass: … frames/s, GPU … ms, CPU … ms per frame; 2560 x 1440 px, … sampled invocations and … primary hits per frame (expected …)
```

It shows the size the RT pass traces, whether the RT shader runs at all and whether its rays hit blocks. Please send this line after testing with RT on.

### Install

Replace the old JAR in `mods` (Fabric Loader 0.19.5+, Fabric API, Vulkan backend).
