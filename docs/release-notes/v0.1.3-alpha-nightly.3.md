## Vulkan Frame Generation nightly 3 (after 0.1.2-alpha)

Untested nightly build for **Minecraft 26.3** (Fabric, Vulkan backend). Expect bugs; back up your worlds. The JAR still carries the version `0.1.2-alpha` in its name.

### New

- **Auto exposure:** RT brightness adapts smoothly to caves, night and bright sun.
- **Light shafts:** sun and moon light scatters through haze, with shadows from trees, windows and cave openings (medium, high and ultra RT quality; denser in rain).

### Fixes

- Caves are no longer lit by the sky and sun through ceilings outside the RT range; RT now uses vanilla's sky light per block.
- Lava is no longer shaded as water.
- Slabs, fences and leaves no longer turn transparent; only glass blocks and panes refract.
- Fewer rays per pixel for bounce light, for better performance.

### Known issues

- Brightness and colours are not tuned yet.
- Ray Reconstruction may still freeze the picture; test RT without it first.

### Install

Replace the old JAR in `mods` (Fabric Loader 0.19.5+, Fabric API, Vulkan backend).
