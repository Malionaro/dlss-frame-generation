# Contributing

Pull requests are welcome. The project uses a custom source-available license ([LICENSE.txt](LICENSE.txt)), so please read this first.

- **Fork, change, open a PR.** Forks exist to contribute back. Do not publish builds or the code elsewhere without written permission.
- **By opening a PR you grant** the maintainer the right to use, change and publish your contribution as part of the project. You keep your copyright.
- **Keep comments short** and only where the code does not explain itself.
- **Run `.\gradlew.bat build`** before opening a PR; it builds the native bridge, compiles the shaders and runs all tests.
- **Bug reports:** include GPU and driver, Minecraft version, the mod list (Sodium, Iris, shader pack), your DLSS and frame-generation settings, and the relevant part of `latest.log`.
